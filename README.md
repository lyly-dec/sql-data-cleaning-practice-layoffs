## SQL Data Cleaning - Layoffs Dataset
# 📌 Overview

This project focuses on cleaning and preparing a layoffs dataset using MySQL.

The project was created as part of my self-learning journey to practice SQL data cleaning techniques and understand how raw data can be transformed into a cleaner and more consistent dataset for further analysis.
## 🎯 Objectives

The main objectives of this project are to:

- Identify and remove duplicate records
- Standardize inconsistent values
- Handle NULL and blank values
- Convert data types
- Fill missing values where possible
- Remove unnecessary columns
- Create a clean staging table for further analysis
